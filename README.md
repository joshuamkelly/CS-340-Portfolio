# CS-340-Portfolio

This repository contains my portfolio artifact for CS 340. The main project in this course involved developing a dashboard for Grazioso Salvare. It involves connecting a dashboard application with a MongoDB database so as to enable filtering and displaying animal shelter data in a practical manner. My artifact in this case comprises the final dashboard code, the CRUD Python module, and my README file from Project Two.

One thing that I have learned while taking this course is that maintainable, readable, and adaptable programs are created in consideration of the responsibility of each part in the whole process. A very good example in this regard is my CRUD Python module developed during Project One. Rather than writing the database connection and query functions repetitively in the dashboard itself, I created them in another module so that the dashboard became easier to understand and update. It was adaptable because I could reuse the CRUD module in future projects that involve using Python in connection with a MongoDB database. In this respect, separation of responsibilities simplifies the programming task.

As a computer scientist in tackling any problem, I normally tend to separate the problem into several components. I ensure that each component of the overall solution works independently before combining all the components into one final program. The importance of this procedure can easily be appreciated by considering the several related requirements of this project such as database implementation, CRUD module, dashboard table, filters, chart, and map functionalities. This project is quite different from most of the assignments in which I simply had to write working code in Python. Here, I was required to develop a solution that matched the clients' desired functionality. In future, if I ever undertake a similar assignment for another client, I will adopt a similar strategy of separating and solving problem components.

Computer scientists design systems that improve efficiency and facilitate decision making. It is important to note that companies and other organizations rely on software for data management purposes and transforming raw data into useful information. In this case, my efforts in designing the database and dashboard could prove beneficial to the Grazioso Salvare Company by improving its operational efficiency and decision-making capabilities. The dashboard could make the company's task of accessing specific data much easier, faster, and accurate.
